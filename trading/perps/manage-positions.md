# Manage positions

Manage Perp positions from `🎯 Active Positions` (Main Menu). Each position shows its asset, direction, leverage, and current PnL. Tap a position to open its controls.

| Button | Function |
| ------ | -------- |
| `🔴 Close Position` | Close (partial or full) |
| `🛑 Stop Loss` | Set or manage stop loss |
| `🎯 Take Profit` | Set or manage take profit |
| `🔄 Refresh Position` | Update position data |

**Close:** click `🔴 Close Position`, choose entire or partial (pick or type a percentage), then approve.

**Stop loss / take profit:** click `🛑 Stop Loss` or `🎯 Take Profit`, set the percentage to close and the trigger price, then approve.

Closed positions are in `📚 Perp History` — see [Perp History](https://docs.fatcatbot.io/trading/perps/perp-history).
