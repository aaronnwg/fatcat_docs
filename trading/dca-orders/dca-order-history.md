# DCA Order History

**Button:** `📔 DCA Order History` (DCA Menu)

Open `⏰ DCA` → `📔 DCA Order History` to review completed and cancelled DCA orders.

Each entry typically shows the token pair, status (Completed or Cancelled), size per execution and frequency, executions completed, and timestamps.

{% hint style="info" %}
DCA orders live on Jupiter's recurring program — you can also review them at <https://jup.ag/recurring>. If your history looks empty, confirm you're viewing the wallet you used for the DCA.
{% endhint %}
