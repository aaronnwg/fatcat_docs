# FatCat Web App

The FatCat Web App is an enhanced trading interface for charts, faster execution, and wallet management. It opens inside Telegram's built-in browser (or your browser on desktop).

**Open it:** Main Menu `📱 FatCat Web App`, or `/webapp`.

### What you get

* Live trading charts.
* Swap any SPL token for any other.
* Full position management (close, edit SL/TP, refresh).
* The **AI Trade** bubble to open the [AI Assistant](../ai-assistant/ai-assistant.md).
* Wallet management and token [sends](../fatcat-bot-telegram/supporting-features/send.md).

Use it when you're watching price action and want to execute quickly.

{% hint style="info" %}
If you don't see charts, retry opening it from the bot button.
{% endhint %}
