# Welcome

FatCat is a non-custodial trading platform built for messaging apps — currently available in Telegram and LINE. It brings the best Solana trading experience right into your hands, and you stay in control of your funds the whole time.

{% include ".gitbook/includes/security-warning-support.md" %}

### What is FatCat?

You sign in and either create a secure Solana wallet or connect an existing one — no browser extensions, separate apps, or seed phrases to set up.

For embedded wallets, FatCat uses Privy: your private key is generated inside a hardware-isolated environment, split into encrypted shares, and never stored as a whole. Neither FatCat nor Privy can access it. FatCat only prepares transactions — nothing executes without your approval, and it can't move funds on your behalf.

### Core features

* **Spot trading** — swap any Solana token for any other.
* **Limit orders** — execute at your target price.
* **DCA** — automate recurring buys or sells over time.
* **Perpetual Futures** — trade Perps with leverage, including stop losses and take profits.
* **AI Assistant** — research tokens, prepare trades, and manage positions in plain language.
* **Send** — transfer tokens to any Solana wallet.
* **FatCat Web App** — a web interface with live charts and full trading, recommended for the best experience.

{% hint style="warning" %}
Perps are high risk, especially at high leverage.
{% endhint %}

### What you'll need

* A Telegram account.
* An email address or phone number (if you create an embedded wallet).
* SOL for network fees and trading.
