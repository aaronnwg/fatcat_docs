# Where to Find Tokens

You can trade most SPL tokens on FatCat, as long as the token has liquidity on a supported pool. To select the right asset, use the token's **mint address** — its unique identifier on Solana. Names and symbols can be copied; the mint address is the exact token.

Example (wSOL): `So11111111111111111111111111111111111111112`

{% hint style="info" %}
A mint address is **not** a wallet address. It identifies the token itself.
{% endhint %}

### Where to get it

Use sources you can verify: official project channels (website, docs, X, Discord, Telegram), trusted explorer token pages, DEX analytics, and launch platforms.

### Verify before you trade

* The mint matches the project's **official** announcement.
* The token has **real liquidity** — thin liquidity means more slippage.
* You're not relying on name or ticker alone.

{% hint style="warning" %}
Same name does not mean same token. Always verify the mint address before trading.
{% endhint %}

If unsure, read [Avoiding Scams](https://docs.fatcatbot.io/safety-and-security/avoiding-scams) and [Trade Safely](https://docs.fatcatbot.io/safety-and-security/trade-safely). For deeper mechanics, see [How Tokens Work](https://docs.fatcatbot.io/tokens/how-tokens-work).
