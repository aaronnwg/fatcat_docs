# Supported Tokens

FatCat can trade most Solana tokens — there's no manual whitelist. If a token has an active liquidity pool on a supported source with adequate liquidity, it's tradable; if there's no supported pool, it won't show up.

### Supported liquidity sources

Raydium · Meteora · Orca · Pump.fun

### Confirm a pool exists

Paste the **mint address** into a DEX tracker, open the top pair, and confirm the venue is one of the sources above with real liquidity and recent volume. If a token isn't showing up, confirm you're searching by mint address and that it has an active pool on a supported venue (brand-new pools may take a moment).

If unsure about a token, read [Avoiding Scams](https://docs.fatcatbot.io/safety-and-security/avoiding-scams) and [Trade Safely](https://docs.fatcatbot.io/safety-and-security/trade-safely).
