# Avoiding Scams

{% hint style="warning" %}
Never share your seed phrase or private key. FatCat support will never ask for them.
{% endhint %}

### Common scam patterns

* **Impersonation / fake support** — support never DMs you first. Anyone asking you to "verify" your private key or seed phrase, or to click a link to "fix" a problem, is a scam. If you didn't start the conversation, treat it as a scam.
* **Phishing links and fake sites** — watch for lookalike domains and fake token pages. Type the URL yourself or use a bookmark.
* **Fake tokens (copycats)** — scammers reuse popular names and tickers. Always verify the **mint address** from an official source.
* **Wallet drainers** — some sites trick you into signing a malicious transaction. Read every signature request; if anything looks off, tap **Reject**.

### If something feels off

Stop and don't sign — cancel the transaction. Review your recent transactions in a trusted Solana explorer, and if you suspect compromise, move remaining funds to a fresh wallet.

{% hint style="info" %}
If you can't independently verify what you're trading, don't trade it.
{% endhint %}
