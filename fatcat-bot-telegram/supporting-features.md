# Supporting Features

These live in the bot's **Main Menu**.

#### 💼 Portfolio

View your wallet holdings and tap any asset to start a buy or sell flow. See [Portfolio](https://docs.fatcatbot.io/fatcat-bot-telegram/supporting-features/portfolio).

#### 📈 PNL (Profit & Loss)

Track daily wallet performance and generate shareable PnL cards. See [PNL (Profit & Loss)](https://docs.fatcatbot.io/fatcat-bot-telegram/supporting-features/pnl-profit-and-loss).
