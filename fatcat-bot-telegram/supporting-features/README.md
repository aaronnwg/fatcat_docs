# Supporting Features

These live in the bot's **Main Menu**.

* **💼 [Portfolio](portfolio.md)** — view your wallet holdings and tap any asset to start a buy or sell flow.
* **📈 [PNL (Profit & Loss)](pnl-profit-and-loss.md)** — track daily wallet performance and generate shareable PnL cards.
* **[Send](send.md)** — transfer SOL or any SPL token to a Solana address, from the bot or the Web App.
