# Supporting Features

### Included features

{% columns %}
{% column %}
#### 💼 Portfolio

View wallet holdings and jump into buy/sell flows.

* Review token balances in your connected wallet.
* Tap any asset to start a **buy** or **sell** flow.

[Portfolio](portfolio.md)
{% endcolumn %}

{% column %}
#### 📈 PNL (Profit & Loss)

Track daily wallet PnL and generate shareable PnL cards.

* See daily performance across your holdings.
* Generate a shareable PnL card.

[PNL (Profit & Loss)](pnl-profit-and-loss.md)
{% endcolumn %}
{% endcolumns %}

#### Send

Transfer tokens from your FatCat wallet to any external Solana wallet.

* Send SOL or any SPL token to a Solana address.
* Available in both the Telegram bot and the FatCat Web App.

[Send](send.md)

### Where to find these

These live in the bot’s **Main Menu**.

* `💼 Portfolio`
* `📈 PNL`
* `Send`
