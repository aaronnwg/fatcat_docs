# Portfolio

**Button:** `💼 Portfolio` (Main Menu)

View your connected wallet's holdings at a glance, and tap any asset to start a **buy** or **sell** flow.

{% hint style="info" %}
If you don't see a token you hold, refresh and confirm you're connected to the right wallet.
{% endhint %}
