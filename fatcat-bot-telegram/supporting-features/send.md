# Send

**Button:** `Send` (Main Menu)

Transfer tokens from your FatCat wallet to any external Solana wallet.

1. Tap **Send** (in the Telegram bot or the Web App's Send tab).
2. Enter the destination address, token, and amount.
3. Confirm. Funds go directly on-chain.

{% hint style="warning" %}
Solana transactions are irreversible. Always double-check the address before confirming.
{% endhint %}

{% hint style="info" %}
You need a small amount of SOL to cover the network fee. You can send any token in your wallet — SOL, USDC, wETH, wBTC, or any SPL token.
{% endhint %}
