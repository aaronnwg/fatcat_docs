# Solana

FatCat trades on Solana — tokens and on-chain Perpetual contracts. Most actions need a small SOL balance for network fees, and a balance that runs to zero can leave you unable to sell or cancel.

### Where to get SOL

A centralized exchange, another supported onramp, or a transfer from another Solana wallet you control.

{% hint style="warning" %}
Only send SOL on the **Solana** network to a Solana address — sending on the wrong network can cause permanent loss. On-chain transactions are final, so always verify the address and network before sending.
{% endhint %}
