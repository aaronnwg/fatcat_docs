# Getting Started

Before you can trade, set up your wallet and fund it with SOL.

FatCat supports Privy embedded wallets and wallet connection — create a Solana wallet when you sign in with your email or phone, or connect an existing one, all inside Telegram. For embedded wallets, neither FatCat nor Privy can access your private key; only you can authorize transactions.

* [Setting Up Your Wallet](setting-up-your-wallet.md) — connect or create your wallet and understand how it's secured.
* [Funding Your Wallet](funding-your-wallet.md) — deposit SOL to start trading.
