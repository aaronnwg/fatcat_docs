# Quick Start Guide

Get from zero to your first trade in a few minutes.

{% stepper %}
{% step %}
### Open FatCat Bot

Open Telegram and start a chat with [FatCat Bot](https://t.me/FatCat_Solbot). Tap Start or send /start.
{% endstep %}

{% step %}
### Connect or create your wallet

1\. Tap Connect Wallet.

2\. FatCat opens a secure page in Telegram’s built-in browser.

3\. Choose whether to connect an existing wallet or create a new Privy wallet.

4\. If you create a Privy wallet, enter your email address or phone number.

5\. If prompted, enter the verification code sent to you.

6\. Complete the wallet flow and return to the bot with your wallet connected.

No browser extensions. No separate apps. If you create a Privy wallet, it is ready immediately. Its private key is secured by hardware-isolated encryption that neither FatCat nor Privy can access.
{% endstep %}

{% step %}
### Fund your wallet

Copy your wallet address from the bot and send SOL to it from an exchange or another wallet. You will need SOL for both trading and network fees.

{% hint style="info" %}
Network fees on Solana are typically fractions of a cent.
{% endhint %}

* See: [Funding Your Wallet](getting-started/funding-your-wallet.md) for more details.
{% endstep %}

{% step %}
### Make your first trade

1\. Tap Buy on the main menu.

2\. Paste a token mint address or pick a token.

3\. Enter the amount of SOL you want to spend.

4\. Review the transaction details.

5\. Tap Confirm to approve the transaction.

6\. Done. Your tokens are in your wallet.
{% endstep %}

{% step %}
### Sell

1\. Tap Sell on the main menu.

2\. Select the token you want to sell.

3\. Choose a percentage or enter an amount.

4\. Review and approve.
{% endstep %}
{% endstepper %}

### Try the FatCat Web App

For a richer trading experience with live charts, portfolio management, sending, and faster execution, open the FatCat Web App from the bot menu. It supports the same core features in a visual web interface, including Swaps, Limit Orders, Perps, Portfolio, and Send. This is the recommended way to trade.

You can also use the [AI Assistant](../ai-assistant/ai-assistant.md) from chat or from the **AI Trade** bubble in the app.
