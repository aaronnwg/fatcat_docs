# Quick Start Guide

Get from zero to your first trade in a few minutes.

{% stepper %}
{% step %}
### Open FatCat Bot
Start a chat with [FatCat Bot](https://t.me/FatCat_Solbot) and tap Start.
{% endstep %}

{% step %}
### Create your wallet
Tap Connect Wallet, enter your email, and enter the verification code. Privy creates a secure Solana wallet — no extensions, apps, or seed phrases.
{% endstep %}

{% step %}
### Fund your wallet
Copy your wallet address and send SOL to it from an exchange or another wallet. You need SOL for trading and network fees. See [Funding Your Wallet](https://docs.fatcatbot.io/overview/getting-started/funding-your-wallet).
{% endstep %}

{% step %}
### Buy
Tap Buy, paste a token mint address, enter the SOL to spend, review, and Confirm.
{% endstep %}

{% step %}
### Sell
Tap Sell, select the token, choose a percentage or amount, then review and approve.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
For live charts and faster execution, open the FatCat Web App from the bot menu — the recommended way to trade.
{% endhint %}
